# DID F186~F197, F15A, F15B 实现说明

## 1. 概述

根据诊断调查表需求，在 Bootloader 和 App 的 UDS 0x22 (ReadDataByIdentifier) 和 0x2E (WriteDataByIdentifier) 服务中实现了以下 DID：

| 序号 | DID | 描述 | 服务 | 实现位置 |
|------|-----|------|------|----------|
| 1 | F186 | Bootloader参考号 | 0x22 Read | Bootloader + App |
| 2 | F187 | OEM零部件号 | 0x22 Read | Bootloader + App |
| 3 | F188 | OEM软件号 | 0x22 Read | Bootloader + App |
| 4 | F189 | OEM软件版本号 | 0x22 Read | Bootloader + App |
| 5 | F18A | 供应商代码 | 0x22 Read | Bootloader + App |
| 6 | F18B | 供应商产品制造日期 | 0x22 Read | Bootloader + App |
| 7 | F18C | 供应商产品生产流水号/批次号 | 0x22 Read | Bootloader + App |
| 8 | F190 | 整车VIN编号 | 0x22 Read | Bootloader + App |
| 9 | F191 | OEM硬件号 | 0x22 Read | Bootloader + App |
| 10 | F192 | 供应商硬件号 | 0x22 Read | Bootloader + App |
| 11 | F193 | 供应商硬件版本号 | 0x22 Read | Bootloader + App |
| 12 | F194 | 供应商软件号 | 0x22 Read | Bootloader + App |
| 13 | F195 | 供应商软件版本号 | 0x22 Read | Bootloader + App |
| 14 | F197 | 控制器名称/系统名称 | 0x22 Read | Bootloader + App |
| 16 | F15A | 诊断仪刷写指纹信息写入 | 0x2E Write | Bootloader Only |
| 17 | F15B | 诊断仪刷写指纹信息读取 | 0x22 Read | Bootloader + App |

## 3. 0x22 服务 (ReadDataByIdentifier)

### 3.1 标准 DID 读取 (F186~F197)

使用 `g_rwDataTable` 通用查询机制：
- 请求格式: `22 F1 86`
- 响应格式: `62 F1 86 <data>`

### 3.2 F15B 特殊处理 - 指纹记录读取

```c
if (did == F15B)
{
    /* 返回所有存储的指纹记录 (最多3条) */
    /* 按时间倒序排列 (最新的在前) */
    for (int r = 0; r < fingerprint_record_count; r++)
    {
        uint8 idx = (fingerprint_write_index + 3 - 1 - r) % 3;
        memcpy(&rsp[3 + r * 67], &data_f15b_fingerprint[idx][0], 67);
    }
}
```

**响应格式**:
- 无记录: `62 F1 5B <67 bytes 空记录>`
- 有记录: `62 F1 5B <record1> [record2] [record3]`

## 4. 0x2E 服务 (WriteDataByIdentifier)

### 4.1 F15A - 诊断仪刷写指纹信息写入 (Bootloader Only)

**请求格式**:
```
2E F1 5A <66 bytes data>
```

**数据布局 (66 bytes)**:
| 字节范围 | 内容 | 长度 |
|---------|------|------|
| 0~15    | 刷写诊断仪设备号 | 16 bytes |
| 16~25   | 刷写前软件号 | 10 bytes |
| 26~35   | 刷写前软件版本号 | 10 bytes |
| 36~45   | 刷写日期 (年月日) | 10 bytes |
| 46~55   | 刷写后软件号 | 10 bytes |
| 56~65   | 刷写后软件版本号 | 10 bytes |

**处理逻辑**:
1. 接收 2E F1 5A 请求
2. 将 66 bytes 数据写入 `data_f15a_fingerprint`
3. 同时复制到 F15B 读取缓冲区的环形缓冲区中
4. 环形缓冲区最多保存 3 条记录，新记录覆盖最旧的

```c
if (did == F15A)
{
    /* Write to F15A buffer */
    memcpy(data_f15a_fingerprint, &data[3], 66);

    /* Copy to F15B ring buffer */
    memcpy(&data_f15b_fingerprint[write_idx][0], data_f15a_fingerprint, 67);
    write_idx = (write_idx + 1) % 3;
    if (count < 3) count++;
}
```

## 6. 注意事项

1. **F15A 仅在 Bootloader 中支持写入**：App 模式下不支持刷写指纹写入
2. **F15B 读取返回所有记录**：如果存储了多条记录，会一次性返回，注意 CAN 帧长度限制
3. **默认数据为占位符**：实际项目中需要根据具体信息修改各 DID 的默认值
4. **指纹记录掉电丢失**：当前使用 RAM 存储，如需持久化请改用 DFlash/EEPROM
